# PixelView

Windows向けの画像ビューア／RAW画素検査アプリです。

[Portable版 PixelView 1.2.37 をダウンロード](https://github.com/wei00565487/pixelview-portable/raw/refs/heads/main/portable/PixelView-1.2.37.exe)

Pythonのインストールは不要です。ダウンロード後にEXEを起動してください。

## ユーザーマニュアル

対象バージョン：1.2.37（Windows Portable版）

PixelViewは、画像の閲覧、ヘッダなしRAWの確認、複数画像の比較、画素値の解析を行うアプリです。設定項目と解析結果は元画像を変更しません。

## 1. 起動と画面構成

1. `portable/PixelView-1.2.37.exe` をダブルクリックします。インストールやPythonの準備は不要です。
2. 前回開いていたフォルダがある場合、起動後に復元します。画像ファイルをEXEにドラッグして起動した場合は、そのファイルの読み込みが優先されます。

画面の左上はフォルダツリー、左下は「プレビュー」「画像情報」のタブ、右側は読み込んだ画像のサムネイルです。画像の読み込み中は下部に進捗を表示します。

古いバージョンのEXEも番号別に残しています。以前の版に戻すときは、使いたい番号のEXEを起動してください。設定は各版で共通のユーザーフォルダに保存します。

## 2. 画像を開く・探す

- **画像を開く**：ツールバーの「画像を開く」または `Ctrl + O`。複数ファイルを選択できます。
- **フォルダを開く**：「フォルダ」または `Ctrl + Shift + O`。左のツリーからフォルダ名を選んでも開けます。ツリーの三角またはフォルダ名で子フォルダを展開できます。
- **上のフォルダへ**：サムネイル上部の `↑` を押します。
- **ドラッグ＆ドロップ**：画像ファイルを画像表示領域へドロップします。複数の画像ファイルを一度に指定できます。
- **検索・並べ替え**：サムネイル上部の検索欄にファイル名の一部を入力します。「ファイル名」「更新日時」「ファイルサイズ」で並べ替えられます。
- **種類の絞り込み**：「すべての画像」「標準画像」「RAW」を選びます。絞り込みは読み込み済みの一覧に対して行います。

フォルダを切り替えると、前のフォルダの読み込み途中の結果は新しい一覧に追加されません。既に開いている画像表示ウィンドウは、開いた時点の画像一覧を保持します。

### ヘッダなしRAWを開く

`.raw`、`.bin`、`.gray`、`.grey`、`.y`、`.bayer` はヘッダなしの画素データとして扱います。開くときに幅、高さ、信号のbit深度、チャンネル数、16 bitのエンディアンを確認してください。

例えば `ColorChecker_2592x1536_12bits_RGGB.raw` は、ファイル名から幅2592、高さ1536、12 bitを初期値として読み取ります。チャンネル数とエンディアンはデータに合わせて確認してください。ファイル名やファイルサイズだけでは形式を確定できません。

- 8 bitは1サンプル1バイトです。
- 9～16 bitは1サンプル2バイトの16 bitコンテナです。信号値は `2^bit深度 - 1` を上限として扱います。12 bitを3バイトに2画素詰める形式には対応していません。
- 画像の指定サイズとファイルサイズが一致しないと読み込めません。
- 前回フォルダの自動復元では、ファイル名から幅・高さ・bit深度を判断できるRAWを、モノクロ・リトルエンディアンとして自動読み込みします。異なる形式は手動で開き直してください。
- `.raw` はヘッダなしRAWとして扱います。圧縮されたカメラRAWの場合は、対応するカメラ固有の拡張子を使用してください。

NEF、CR3、ARW、DNGなどのカメラRAWは、同梱のLibRaw対応範囲で現像して表示します。メーカー純正ソフトと同一の色になるとは限りません。

## 3. 画像表示と画素値

サムネイルをダブルクリックすると、画像表示ウィンドウが開きます。

| 操作 | 動作 |
| --- | --- |
| 左ドラッグ | 画像を移動 |
| マウスホイール | 画像の表示中心を基準に拡大・縮小 |
| `F` | 全体表示に戻す |
| `←` / `→` | 画像表示を開いた時点の一覧で前後に移動 |
| `F11` | 全画面表示／復帰 |
| `Esc` | 全画面から復帰。通常ウィンドウでは閉じる |
| 画像上にポインタを置く | 座標と元画像の画素値を表示 |

表示ウィンドウの倍率は、画面に合わせた初期表示を100%とする倍率です。「拡大時に最近傍」を有効にすると、元画像に対して100%以上の拡大で画素を混ぜずに表示します。

メイン画面の「画像情報」タブでは、寸法、ファイル情報、取得できるEXIF、RAWの読み込み設定などを確認できます。画素値・画像情報・ファイルパスは、対応するボタンや「編集」メニューからコピーできます。

## 4. 画像全体のヒストグラム

画像を選び、`Ctrl + H` または「解析 → 画像全体のヒストグラム」を選びます。画像表示ウィンドウや、並べて表示の「ヒストグラム」からも開けます。

- カラー画像は輝度、R、G、Bを切り替えます。モノクロ画像は信号値を表示します。輝度は `0.299 R + 0.587 G + 0.114 B` の丸め値です。
- 元の信号範囲を256階級に分け、全画素を集計します。RAWは8 bitプレビューではなく元のRAW値を使います。
- グラフ上にポインタを置くと、その階級の値の範囲と画素数を確認できます。
- 「CSVに保存」で全チャネルの階級範囲と度数を書き出せます。

## 5. 範囲統計・波形・しきい値

### 範囲統計

画像表示で右ドラッグすると、選択範囲の平均、母標準偏差、SNR、ヒストグラム、水平／垂直プロジェクションが表示されます。水平プロジェクションは各行の平均、垂直プロジェクションは各列の平均です。

SNRは `20 × log10(|平均| / 標準偏差)` です。標準偏差が0の一定値は∞、平均も標準偏差も0の場合は未定義です。モノクロ画像は同じ信号値をR/G/Bの行に表示します。

「解析操作 → 選択範囲の統計をCSV保存」で、範囲座標、ファイル情報、RAW設定と統計値を保存できます。CSVの `x1_exclusive` と `y1_exclusive` は範囲に含まれない終端座標です。

### 線プロファイル

1. 画像表示の「右ドラッグで線プロファイル」を有効にします。
2. 画像上を右ドラッグします。横方向の移動が大きいと水平線、縦方向が大きいと垂直線を選択します。
3. 波形を確認し、必要なら「CSVに保存」を押します。CSVには元画像の座標と画素値が入ります。

表示幅より長い線は、各表示区間の最小・最大と平均をグラフに示します。CSVには線上の各画素を出力します。範囲統計に戻すときはチェックを外します。

### 黒・白しきい値

画像表示の「解析操作 → 黒・白しきい値表示」で、黒側と白側のしきい値を入力します。黒側以下の画素は青、白側以上は赤、両方に該当する画素は紫で表示します。RGB画像は、いずれかのチャネルが条件を満たす画素を数えます。件数と割合はダイアログで確認できます。

表示を戻すときは「解析操作 → しきい値表示解除」を選びます。

## 6. 複数画像の比較

### 並べて表示

1. サムネイルを `Ctrl` を押しながらクリックし、2～4枚を選びます。
2. 「並べて表示」を押します。2～3枚は横一列、4枚は2×2で表示します。
3. 左ドラッグで全画像を同期移動します。`Shift + 左ドラッグ` は対象ペインだけを移動します。ホイールは同期ズームです。

比較の基準となる「1枚目」は、サムネイルの現在の並べ替え順で先に表示される選択画像です。並べて表示の各画像は「ヒストグラム」から個別に確認できます。

検索や種類の絞り込みでサムネイルが隠れても、その画像の選択は維持されます。隠れている選択画像は、表示中の選択画像の後に比較対象として追加されます。

### 差分画像

並べて表示の「1枚目との差分」で、2枚目以降を基準画像との差分に切り替えます。差分倍率は初期値4倍で、0.01～65536を指定し「差分設定を適用」で反映します。

- **絶対差**：差の大きさを表示します。
- **正負差**：比較画像の値が基準より大きい成分を赤、小さい成分を青で表示します。RGBで両方がある画素は紫になります。

差分は元の信号値から計算し、各画像の信号最大値を白として表示用に変換します。表示値が白を超えるとクリップされます。メイン画面の `D` でも現在の画像と次の画像を切り替えて差分表示でき、「比較 → 差分表示の設定」で倍率と方式を指定できます。

### 数値比較と範囲比較

「差分の数値」または「比較 → 選択画像の差分を数値で比較」を選ぶと、平均差、MAE、RMSE、PSNR、最大絶対差、差のある画素数を表示します。差分の符号は **比較画像 − 基準画像** です。RGBの各チャネル、またはモノクロRAWのBayer各位相についても指標を表示します。Bayer位相はRAW現像画面で選択した配列に従います。

並べて表示で右ドラッグすると、同じ座標範囲を全ペインに示してその範囲の数値比較を開きます。「範囲解除」で全画像の比較に戻ります。結果はコピーまたはCSVに保存できます。

比較対象は、画像サイズ、チャンネル数、信号範囲、およびRAW／通常画像の種類が一致する必要があります。自動位置合わせは行わず、同じ画像座標どうしを比較します。PSNRは信号の最大値をピーク値とします。

## 7. Bayer位相・サンプリング分割

画像表示で「分割表示」を押し、行数と列数を指定して「画像を分割表示」を押します。例えば2行×2列なら、連続した4領域ではなく、元画像の `[0::2, 0::2]`、`[0::2, 1::2]`、`[1::2, 0::2]`、`[1::2, 1::2]` をそれぞれ表示します。

- ホイールで同期ズーム、左ドラッグで同期移動、`Shift + 左ドラッグ` で個別移動します。
- いずれかのペインで右ドラッグすると、対応する座標を他のペインにも適用し、ペイン別の統計を表示します。奇数サイズなどで対応画素がない場合は「対応範囲なし」と表示します。
- モノクロBayer RAWでは「Bayer位相 (R / Gr / Gb / B)」から各位相を色分けして表示できます。配列はRAW現像画面で設定したRGGB / GRBG / GBRG / BGGRを使用します。

## 8. RAWカラー現像

1. 1チャンネルのモノクロBayer RAWを開き、画像表示の「RAWカラー現像」を押します。
2. Bayer配列をRGGB / GRBG / GBRG / BGGRから選びます。
3. 必要に応じてOPB補正を有効にし、R / Gr / Gb / Bの黒レベルを手入力します。画像からOPBは推定しません。
4. デジタルゲイン、R/Bホワイトバランスゲイン、CCM、ホワイトクリップ値、ガンマ値を設定し、「プレビュー更新」を押します。設定欄はスクロールできます。
5. 自動WBを使う場合、画像上の白または無彩色の領域を右ドラッグし、「選択領域からWB自動計算」を押します。
6. 「現像画像を名前を付けて保存」でPNG、JPEG、BMP、TIFF、WebPを選びます。

CCMは3行×3列の数値で、行が出力R / G / B、列が入力R / G / Bに対応します。初期値は単位行列（対角が1、その他が0）で、信号を変化させません。Excelの3行×3列をコピーし、「Excelから貼り付け」を押すか、CCMの入力欄に `Ctrl + V` で貼り付けられます。各セルを個別に編集することもできます。「単位行列に戻す」で初期値に戻ります。貼り付け後は「プレビュー更新」を押してください。

処理順は、OPB黒レベル差し引き → デジタルゲイン → Menon 2007デモザイク → R/Bゲイン → CCM → ホワイトクリップと正規化 → ガンマ補正です。ホワイトクリップはRAW信号の整数値（1～65535）で指定し、その値を白に対応させます。初回値はRAWのbit深度の最大値です。保存画像は8 bit RGBです。

現像画面では左ドラッグで移動、ホイールで拡大・縮小します。WB、OPB、デジタルゲイン、CCM、白クリップ、ガンマ、Bayer配列は次回起動時に復元されます。元RAWは変更されません。

現像画面の設定パネル上部に、現在の現像結果のRGBヒストグラム、水平プロジェクション（行ごとのRGB平均）、垂直プロジェクション（列ごとのRGB平均）を表示します。グラフは「プレビュー更新」または自動WBの再現像が完了すると更新されます。解析対象は設定値が反映された現像後の8 bit RGB画像全体です。

## 9. ヘッダなしRAWとして保存

画像を選び「RAW保存」または `Ctrl + Shift + S` を押し、保存先と形式を指定します。8 bitまたは16 bit、GrayまたはRGB、16 bitのエンディアンを選べます。

ヘッダには寸法やbit深度が保存されないため、再度開く際は同じ形式を指定してください。RAW元画素を同じ寸法で16 bit保存する場合は元の信号値を保持します。8 bitへ保存する場合は元の信号範囲を8 bitに変換します。

## 10. 設定と困ったとき

- 設定ファイルは `%APPDATA%\PixelView\settings.json` にあります。前回フォルダとRAW現像設定を保存します。
- RAWが開けない場合は、ファイルサイズ、幅、高さ、チャンネル数、bit深度、エンディアンを確認してください。
- ファイル名からRAWを自動認識できない場合は、画像を手動で開いて形式を指定してください。
- 差分を計算できない場合は、対象の寸法、チャンネル数、RAWか通常画像か、信号bit深度を確認してください。
- 大きな画像の読み込みや現像、全画素の解析には時間とメモリが必要です。読み込み・差分・全画像ヒストグラム・数値比較はバックグラウンドで処理します。
- カメラRAWや画像形式によっては、同梱ライブラリが対応していないファイルがあります。
